DSH-IDE

将 DSH Web GUI 改造为类 VS Code 的编程 IDE

React 18 TypeScript Monaco Editor xterm.js Vite 5 Tailwind CSS

📝 多标签页编辑器

基于 Monaco Editor，支持语法高亮、自动补全、Minimap，提供专业的代码编辑体验。

📁 文件资源管理器

树形文件浏览，支持搜索、快速导航，让文件管理变得简单高效。

💻 集成终端

基于 xterm.js，支持多终端标签、命令历史，让终端操作更加便捷。

⚡ 命令面板

Ctrl+Shift+P 快捷键，快速执行命令，模糊搜索，提升开发效率。

🔍 快速打开

Ctrl+P 快速打开文件，支持符号搜索和行号跳转，快速定位代码。

📐 编辑器分屏

支持水平/垂直分屏，多窗口同时编辑，提升多任务处理能力。
