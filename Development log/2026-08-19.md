## 技术亮点 / Technical Highlights

### 1. 状态管理设计
使用 Zustand 进行状态管理，分为四个独立的 store：
- `editor-store.ts`：管理编辑器标签页和分屏
- `file-store.ts`：管理文件树和文件操作
- `terminal-store.ts`：管理终端标签和配置
- `ui-store.ts`：管理 UI 状态（侧边栏、主题等）

### 2. 组件化架构
采用 React 组件化设计，每个功能模块独立封装：
- 布局组件：负责整体界面结构
- 功能组件：负责具体功能实现
- 通用组件：可复用的 UI 组件

### 3. 插件注入机制
通过 DSH 插件系统实现无侵入式集成：
- 宿主侧：注册 API 路由和系统提示
- 客户端：注入 IDE 界面到 DSH Web GUI
- 设置系统：提供插件配置界面
