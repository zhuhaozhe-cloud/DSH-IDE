# 今日项目简介 / Today's Project Introduction

> 日期 / Date：2026-08-18

## 项目 / Project

**DSH-IDE** —— 将 DSH（DeepSeek Harness）Web GUI 改造为类 VS Code 的编程 IDE。

**DSH-IDE** — transforming the DSH (DeepSeek Harness) Web GUI into a VS Code–like programming IDE.

---

## 项目概述 / Overview

本项目采用「插件注入 + Web 前端」双线结构，在不修改 DSH 源码的前提下，通过插件体系在 DSH Web GUI 中注入完整的 IDE 界面，并对标 VS Code 的核心交互体验。

This project follows a dual-line structure of "plugin injection + web front-end". Without modifying the DSH source code, it injects a complete IDE interface into the DSH Web GUI via the plugin system, targeting the core VS Code interaction experience.
